v0.3.2 ~ v0.3.6 · 现代 WebRTC 底座
DTLS 1.3 加密证书 + 双 SSRC + MTU 1488
  • Dtls::new_auto 优先 RFC 9147 DTLS 1.3（双向 ECDSA P-256 证书 100% 加密、跨洋省 1 RTT），兼容 1.2 滚动升级，支持 --dtls-min-version 1.3 防降级。
  • 协商 DTLS 1.3 自动启用音视频双 SSRC（PT=111 Opus ≤50 pps + PT=96 90kHz 严格 M=1 因果），独立 2048 槽 RFC 6479 防重放环与正交 Nonce 域。
  • 默认 --mtu 1488 彻底消除 PPPoE 1492B IPv4 分片；内置双模式 12 项自测与带内 0xFFFE 加密回显。
v0.3.7 ~ v0.4.0 (V4.0) · 换路不换门牌
1-RTT 黑洞迁移 + MBB 0xFFFC 原子过户
  • 1-RTT ICE 黑洞迁移（0xFFFD）：保留 PFS 密钥与 SRTP 序列号，以每会话 HKDF 密钥 ice-pwd-v4 签名迁移 STUN，经防反射（≤1.32x）加密挑战验真后原地更新 peer_addr，0 DTLS 重握、0 后端换口。
  • MBB 无感轮换（0xFFFC）：按对数正态时长或字节预算发起全新不可关联 DTLS 1.3，凭双会话 HKDF 证明原子移交 backend_sock（支持跨 worker 无锁转发），延迟 2–10s 发旧流 BYE，实测 0 丢包 0 换口。
  • SIGTERM 广播优雅 SRTCP BYE + close_notify（0.23s 快切）；空闲/微流自动退避控制面并严格遵守 RFC 3550 零媒体 RC=0 语义。
v0.4.1 ~ v0.5.0 · 轻量化、批量 I/O、ECMP 与旁路
解耦遥测 + 双栈优车道 + recvmmsg + bypass
  • 旁路健康遥测（原子 JSON --status-file + 单线程 mio HTTP/Prometheus --status-http），纯隧道仅 1 线程（开遥测 2 线程），x86_64 静态 musl 压至 ~2.0 MiB。
  • 原生双栈 IPv4/IPv6 与 --lane-hunt 多维自适应优车道（无阈值冷启动校准、SRTP 数据面真实丢包评分、Canary 确认与 0ms MBB 逃逸），辅以 Linux --udp-batch 批量收发与 4/8 MiB 突发缓冲。
  • 新增一级旁路直通模式 bypass / bypass --responder：共享五元组带外 STUN 抽卡切路 + 数据面 0 封装原始 UDP 透传（兼容内核 UDP GSO）。
v0.5.1 ~ v0.6.0 · 原生中继、反向隧道与全架构 SIMD
零回环 relay + 零入站 reverse + 16 架构算力补齐
  • 原生单进程中继（relay）：单线程 mio 融合入站终止与出站 bypass/cloak，消除本地回环，实测中继 CPU 降 29%–59%、上下文切换降 68%–79%、峰值吞吐升 +17% ~ +20%。
  • 原生反向隧道（reverse --entry | --agent）：内网/NAT 侧零入站端口，常驻 DTLS 1.3 隧道内借 0xFFFB 按 flow_id: u32 复用多条 UDP 流（固定后端源端口、0-RTT 首包、完整 MBB/1-RTT/--lane-hunt）。
  • 全架构 SIMD 补齐：补齐非 AVX x86 硬件 SSE2+PCLMULQDQ、全 64 位常时间 radix-2^44 Poly1305（Apple Silicon ChaCha20 提速 +23.5% 至 4,027 Mbps）、x86 AVX-512 ChaCha20 与 webrtc-cloak cpu 真实后端诊断。

客观工程定位与适用边界： 本项目定位为面向 Hysteria 2 / QUIC / WireGuard 的高性能透明 UDP 抗干扰传输外壳，核心解决两类现实问题：① 状态化中间件对裸高熵 UDP 的特征识别、QoS 限速与主动探测暴露；② CGNAT / 防火墙导致的单向上行黑洞、长流五元组关联与 PPPoE 分片掉速。它不是通用 TCP/TUN VPN，内层业务机密性始终由上层协议独立保障；在持续突发丢包 ≥15% 或彻底禁止 100% UDP 出口的网络策略下应回退至常规 TCP 传输线路。
