4. V3 → V4.0 (v0.7.0) 关键演进、实测指标与客观边界

v0.3.2 ~ v0.4.0 (V4.0) · 现代底座与无感承载
DTLS 1.3 + 双 SSRC + 1-RTT 迁移 + MBB 原子过户
  • RFC 9147 DTLS 1.3（双向 ECDSA P-256 证书 100% 加密）+ 音视频双 SSRC 正交 Nonce（独立 2048 槽 RFC 6479 环）+ PPPoE --mtu 1488 零分片。
  • 1-RTT 黑洞迁移（0xFFFD）：以 mi_key_mig 签名迁移 STUN，经防反射加密挑战（61B）验真后原地切换 peer_addr，0 DTLS 重握、0 后端换口。
  • MBB 无感轮换（0xFFFC）：按对数正态时长或字节预算发起全新不可关联 DTLS 1.3，原子过户后端管道，实测 0 丢包 0 换口。
v0.4.1 ~ v0.5.0 · 轻量化、ECMP 优车道与旁路
解耦遥测 + 双栈优车道 + Linux recvmmsg + bypass
  • 旁路健康遥测（原子 JSON --status-file + 单线程 mio HTTP/Prometheus --status-http），纯隧道常驻 1 线程（开遥测 2 线程）。
  • 原生双栈 IPv4/IPv6 与 --lane-hunt 多维自适应优车道（冷启动校准、SRTP 数据面真实丢包评分、Canary 确认与 0ms MBB 逃逸），辅以 Linux --udp-batch 批量收发与 4/8 MiB 缓冲。
  • 一级旁路直通 bypass / bypass --responder（仅限非 DPI 路由优选）：68B 带外 STUN 抽卡 + 原始 UDP 透传（兼容内核 UDP GSO）。
v0.5.1 ~ v0.6.0 · 原生中继、反向隧道与全架构 SIMD
零回环 relay + 零入站 reverse + 16 架构算力补齐
  • 单进程中继（relay）：单线程 mio 融合入站与出站（bypass / cloak / reverse 三态），消除本地回环，中继 CPU 降 29%–59%、峰值吞吐升 +17% ~ +20%。
  • L4 UDP 反向隧道（reverse --entry | --agent）：NAT 侧零入站端口，借 0xFFFB 按 flow_id: u32 多流复用（固定源端口、0-RTT 首包、完整 MBB/1-RTT）。
  • 全架构 SIMD：非 AVX SSE2+PCLMULQDQ、全 64 位常时间 radix-2^44 Poly1305（Apple Silicon ChaCha20 提速 +23.5% 至 4,027 Mbps）、x86 AVX-512 ChaCha20。
v0.7.0 · 零回环内嵌类 Hy2 代理 & 三轮红蓝对抗加固
内嵌 proxy (正向/反向) + Chrome/BoringSSL 深度对齐
  • 内嵌类 Hy2 代理（proxy --client | --server, --reverse）：单线程 mio 融合 No-op quinn-proto + Brutal + RFC 9221 UDP + SOCKS5/--tcp-forward + 异步 DNS/CIDR ACL；回环直通 1,586–2,037 Mbps、交互 p95 0.1–0.4 ms、双向视频帧尾包整形、SIGKILL 0 句柄泄漏（可用 --no-default-features 裁剪）。
  • 定制 patches/dimpl DTLS 1.3 加固：默认锁定 V13Only（0 降级、0 明文证书）、0% HRR、0% 0x0015、BoringSSL 首位/末位 GREASE 书立 + 套件/SRTP 序、RFC 9147 §4.2 密文内层随机填充、拼接尾包损坏 10/10 在 274–409ms 恢复。
  • 全栈协议细节硬化：端点域分离 STUN HKDF（--stun-scope）、±10s 窗口、Ready 态 mi_key_mig 保活、HuntUfragTable 墓碑、动态 24/28B RFC 8285 + P=1 SRTP、30/60 FPS 量化视频时钟与异步 BYE → close_notify。

客观工程定位与适用边界（v0.7.0）： 本项目提供透明 UDP 封装（client/server/relay/reverse）与可选零回环内嵌 SOCKS5/TCP 转发代理（proxy），非内核 TUN VPN；v0.7.0 线格式与密钥域不向前兼容 v0.6.x（DNAT 场景使用 --stun-scope 对齐）。bypass 仅用于非 DPI 链路的 ECMP 路由优选，不提供抗 DPI 封装且不可直接承载无加密内层 proxy；在彻底禁止 100% UDP 出口或高强度单租户宏观 NetFlow 流量分析场景下仍存在物理与拓扑边界。
